# 剪辑导演（Beta）

面向长播客、访谈和圆桌的内容策划与音视频后期 Skill，技术 ID 为 `podcast-post-production`。

**[下载 0.6.1-beta 公开预发布版](https://github.com/caphinttytwo-code/podcast-post-production-public/releases/tag/v0.6.1-beta)**

本版显示转写缓存覆盖范围和时间戳证据，区分计划与实际提交量，并为锁版验证增加 `--stdout` 只读 JSON 输出。保留内容策划、音频精剪和同步多轨、完整视频对版、片花包装、字幕修订及项目盘点。

包内包含环境检查、安装、快速及完整合成测试、API 和费用说明。媒体制作要求配对 FFmpeg／FFprobe 最低 8.1.1，其他依赖按功能检查。项目素材、缓存和报告保存在包外。
