# 0.3.0-beta 本地开发候选

显示名称为“剪辑导演（Beta）”，技术 ID、目录名及 `$podcast-post-production` 保持兼容。本候选从经过指纹核验的 0.2.0-rc.6.3-beta 运行包快照派生；这是接续基线，不声称等于上游维护分支最新提交。MIT 许可、原模块来源和冻结测试资料保留。

新增 `editorial-plan`：长节目素材地图、目标时长取舍、补录编排和逐版决策。它可以独立输出方案；只有确认的具体删改才移交原执行模块。`audio-edit` 新增显式选择的 `target-runtime` 内容分支，原严谨单口、保留原声、同步多轨、字幕及其他四模块继续沿原工作流。没有新建通用 EDL，也没有把新策划 JSON 接入媒体渲染器。

入口及辅助脚本可执行本地检查，策划检查器不渲染、不调用模型、不生成用户授权。哈希只能证明当前文件一致，不能证明留言来自真人；执行器仍读取真实选择和授权范围。已有项目无须批量迁移；新增策划索引仍用原 `project-index` schema 1.0，新 workflow 值为 `editorial-plan`。

本候选未发布、未安装、未切换运行版。新维护项目应先定位真实维护仓库及最新提交，再审阅相对基线的增量并整合，不能用本候选覆盖维护目录或全局安装目录。本候选的自建 manifest 是完整性证据，不是远程发行签名。

本轮生成审计保存在候选包外的 `audit/`，包括基线、逐文件差异、测试日志和最终文件清单；本地路径及项目资料不作为通用包内容。发布、GitHub 同步、运行版部署及整理均交由后续项目处理。本包继承的 setup 安装命令只是工具能力，不构成本次安装授权。

验证需区分：本地离线脚本与合成素材回归、独立行为演练、实际宿主路由、真实账号/上传/费用、人工全长审听和发布。没有实际执行的类别记 `NOT RUN`，不沿用 rc6.3 历史通过数量。未实现通用结构试听界面；段落试听沿用既有支持范围，跨段搬移的试听需项目明确授权并单独生成。
