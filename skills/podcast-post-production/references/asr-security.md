# Beta 转写安全与缓存边界

本版继承 rc.6.1 的安全处理：新转写请求拒绝所有 HTTP 跳转，包括同 origin。不会自动改用返回的地址、把 Authorization 发到跳转目标或为跳转循环重试。遇到“ASR HTTP ... redirect rejected”时先保留已完成缓存，核实服务商正式地址和上传／计费范围；对应授权确认后以新的明确地址重试。不得把失败解释为授权自动扩大，也不得临时回退旧脚本。

此更改保持 CLI 参数、原始 SSE 事件、缓存文件名、完整缓存离线复用和缺块续跑。正常200响应按旧格式保存；遇拒绝跳转，已成功的块不覆盖、失败块不生成成功缓存。测试用合成字节与临时本机 HTTP 服务，不访问真实模型或系统凭据。

同地址、跨 origin、301／302／303／307／308、循环、敏感 Location 和失败续跑均有实际本机正常控制／反例。HTTPS 降级策略用真实拒绝处理器的单元调用验证，未进行真实 TLS 模型调用，不宣称账号或云端协议通过。

tests/resources/frozen-sources.zip、rc5-source-updates.zip 的旧源码仅作离线行为对比，其中旧请求实现不适合恢复生产使用。rc6-source-updates.zip 保存本轮修复源码、测试及适配差异。资料解压到包外，不安装为另一 Skill、不调用其中旧 API 入口。

本包为公开 Beta，许可见 NOTICE.md。此安全修复不代表软件已完成跨平台、真实宿主路由、账号验证或人工完整审听／审看。
